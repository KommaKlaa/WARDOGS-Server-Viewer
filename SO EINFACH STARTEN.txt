WARDOGS Server Viewer — so startest du / quick start

DEUTSCH
=======
1. Einmalig Node.js 22 LTS installieren:
   https://nodejs.org/

2. Doppelklick auf:
   Start WARDOGS Viewer.bat

3. Browser öffnet sich automatisch.
   Fenster offen lassen.
   Fenster schließen = beenden.

Ausführliche Anleitung: README.de.md
Support: GitHub Issues
https://github.com/KommaKlaa/WARDOGS-Server-Viewer/issues

ENGLISH
=======
1. Install Node.js 22 LTS once:
   https://nodejs.org/

2. Double-click:
   Start WARDOGS Viewer.bat

3. Browser opens automatically.
   Keep the window open.
   Close the window to quit.

Full guide: README.md
Support: GitHub Issues
https://github.com/KommaKlaa/WARDOGS-Server-Viewer/issues
